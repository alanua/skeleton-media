# R19 MPV/HLS observation review

Current MPV status omits cache metrics, health sanitization drops them, and existing update_stall excludes buffering samples. A source-starved stream can therefore evade the normal stall path. This source-only patch collects bounded scalar cache/seek/end/session observations and classifies comparable MPV samples. It distinguishes healthy pause, transitions, stale/unknown evidence, buffering recovery, cache starvation and clock/frame stalls. Cache metrics alone never prove a network root cause; HTTP200 alone never proves a complete transfer.

It reuses existing collect output. select_repairs, execute_repair, watchdog and update_stall are AST-unchanged. No new daemon, service, default repair, mode switch or device input. Full re-resolution/alternate-source recovery remains required by Skeleton#4937 and#4928; this observation patch does not claim it.
